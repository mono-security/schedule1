Расписание ТД-26-11-1 на GitHub Pages
=====================================

Что это
-------
Готовый сайт. GitHub сам скачивает ЭУиК.xls с Яндекс Диска
по понедельникам–субботам с 6:00 до 18:00 (Москва), раз в час.
Кнопки ручного обновления нет — так Яндекс не блокирует запросы.
Grok и VPN для этого не нужны.

Сайт будет по адресу:
  https://ВАШ-ЛОГИН.github.io/schedule/


Как выложить (только мышкой, без программ)
------------------------------------------

1. Зайдите на https://github.com и создайте аккаунт.

2. Справа сверху нажмите "+" → "New repository".
   Имя: schedule
   Выберите Public
   Ничего больше не отмечайте
   Create repository

3. На пустой странице репозитория нажмите
   "uploading an existing file".

4. Распакуйте этот архив на компьютере.
   Перетащите сюда ВСЕ файлы и папки изнутри архива
   (index.html, schedule.json, папку scripts,
   папку .github — её важно не забыть).
   Commit changes.

   Если папку .github компьютер прячет:
   в GitHub нажмите Add file → Create new file,
   имя файла: .github/workflows/update.yml
   и вставьте содержимое из файла
   .github/workflows/update.yml этого архива.

5. Включите сайт:
   Settings (вкладка репозитория)
   → Pages (слева)
   → Branch: main
   → папка: / (root)
   → Save

   Через 1–2 минуты откроется
   https://ВАШ-ЛОГИН.github.io/schedule/

6. Включите автообновление:
   вкладка Actions → если GitHub спросит,
   нажмите "I understand..."
   → слева "Обновить расписание"
   → Run workflow
   Это первый запуск. Дальше робот будет
   ходить на Яндекс Диск сам:
   понедельник–суббота, каждый час с 6:00 до 18:00
   по московскому времени.


Важно
-----
GitHub иногда тоже недоступен без VPN в некоторых сетях.
Если github.io не открывается — напишите, можно
выложить то же самое на другой бесплатный хостинг.
